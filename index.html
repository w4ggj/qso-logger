QRZ Callsign Lookup
—
Lookups try QRZ first (worldwide, needs a QRZ XML subscription), then fall back automatically to the free callook.info and HamDB callbooks (US coverage, no account) — so callsign info still fills in even with the QRZ fields left blank.

To enable QRZ: deploy the included qrz-proxy-worker.js as a free Cloudflare Worker, paste its …workers.dev URL above, and enter your QRZ username/password. The worker keeps credentials off the public web and adds the CORS headers browsers require — no shack PC or bridge needed.

Requires a QRZ XML Data subscription for QRZ data.
CAT — Rig Control (IC-706MKIIG)
Not connected
Auto-fill: ON
Connects to the radio over the CAT cable using your browser's Web Serial API — no extra software needed. Chrome or Edge on desktop only (over HTTPS).

On the radio, set SET → CI-V Baud to match the dropdown (19200 recommended) and keep CI-V Address = 58h. Turn CI-V Transceive = ON so dial changes update instantly.

Click CONNECT RIG, pick the CAT cable's serial port in the browser prompt, and the live frequency, band, and mode fill in automatically as you tune. Uncheck Auto-fill to just monitor without overwriting the entry fields.

Wheel tuning: click the Frequency field, then scroll the mouse wheel (or press ↑/↓) to step the frequency — Shift for 100 Hz, Alt for 10 kHz. With the rig connected each step is sent to the radio, so the wheel acts as the VFO knob; with no rig connected it just sets the entry field.
